# Changelog

## 3.0.0 — 2026-09-09

- Refreshed the editorial design with fluid Inter typography, generous spacing, handwritten SVG marks, and a fine-lined canvas.
- Added light and dark themes, a persistent navigation light switch, and matching variants for the sample product images.
- Added local full-text article search with an expanding navigation input and a dedicated results page.
- Reworked article rows, publication metadata, Markdown typography, and related reading.
- Expanded the About page, archive and topic introductions, topic descriptions and counts, footer, and 404 page.
- Exposed article topics in the editor and added an optional topic description field.
- Improved the mobile menu, keyboard focus, Escape handling, hidden control behavior, and reduced-motion support.
- Moved component styling into Tailwind utilities and fixed the font-import build warning.
- Preserved the original sample stories, entry IDs, URLs, and mobile hamburger fix.
- Updated the README, screenshots, and square marketplace thumbnail.
